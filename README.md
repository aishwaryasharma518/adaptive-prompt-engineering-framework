Adaptive Prompt Engineering Framework

A Python-based application that explores how different prompt engineering techniques can improve the quality, reliability, and consistency of responses generated by Large Language Models (LLMs).

About the Project

The Adaptive Prompt Engineering Framework is a research-oriented project that focuses on selecting and applying suitable prompting techniques based on the type of user query.

Different tasks require different approaches to prompting. This application attempts to address that by identifying the task category, selecting relevant techniques, and generating a structured prompt before sending it to a locally running language model.

It also includes a basic response evaluation mechanism to identify potentially overconfident language, check for evidence-related statements, and flag predefined stereotypical expressions. Based on the evaluation, the framework can generate a refined prompt and produce an improved response.

Features

- Task-Based Technique Selection: Selects prompting techniques according to the chosen task, including question answering, text classification, code generation, and cybersecurity analysis.

- Multiple Prompting Techniques: Covers nine techniques: Zero-shot, Few-shot, Chain-of-Thought, Role-based, Structured, Iterative, Test-driven, Retrieval-Augmented Generation (RAG), and Query Transformation.

- Query Transformation: Expands short queries into clearer and more structured instructions.

- Optimized Prompt Generation: Combines selected techniques with instructions focused on clarity, evidence, uncertainty, and responsible responses.

- Local LLM Integration: Uses Qwen 2.5 (1.5B) through Ollama to generate responses locally.

- Response Evaluation: Checks response length, evidence-related wording, uncertainty indicators, recommendations, potentially overconfident phrases, and predefined stereotype expressions.

- Prompt Refinement: Uses the evaluation results to identify areas for improvement and generates a second response using a refined prompt.

Application Workflow

1. The user selects a task category.
2. The user enters a query.
3. The framework selects relevant prompting techniques.
4. Short queries are transformed into structured instructions when required.
5. An optimized prompt is generated.
6. The prompt is processed using the Qwen language model.
7. The generated response is evaluated using predefined indicators.
8. A refined prompt is created based on the evaluation.
9. The user can generate and review an improved response.

Getting Started

Prerequisites

- Python 3.9 or later
- Ollama
- Qwen 2.5 (1.5B) model

Installation

1. Clone the repository

git clone https://github.com/aishwaryasharma518/adaptive-prompt-engineering-framework.git

2. Open the project directory

cd adaptive-prompt-engineering-framework

3. Install the required packages

pip install streamlit ollama

4. Download the language model

ollama pull qwen2.5:1.5b

5. Run the application

streamlit run app.py

The application will open in your default web browser.

Current Limitations

The current version is a working prototype, and some features have scope for further development.

- The response evaluation process is based on predefined keywords and phrases rather than advanced semantic analysis.
- Bias screening covers only a limited set of predefined expressions.
- RAG is included as a recommended technique, but document retrieval and external knowledge integration are not implemented.
- Test-driven prompting can suggest test cases, but does not execute them automatically.
- The evaluation indicators provide preliminary observations and cannot guarantee factual accuracy or the absence of bias.

Future Scope

Some possible improvements include:

- Integrating a document-based RAG pipeline.
- Adding more advanced bias and reliability evaluation methods.
- Supporting additional language models.
- Introducing automated code testing.
- Evaluating performance using benchmark datasets.
- Improving the accuracy and explainability of response evaluation.
